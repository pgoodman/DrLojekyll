## §1 What the cut IS

A new anon-namespace static `ClassifyFusableComponents(R, instances)` in `Planning.cpp`, run in
`FrozenRegionalProgram::Build` **immediately after** `PromoteSharedSymbolicField` (`Planning.cpp:760`,
before census at `:763`). It reads ONLY:
- `R.recursive_components` (P6.1 — SCC member sets),
- `R.rules` (P6.2 — per-clause `(body_field → head_field)` routes, **clause-source**), and
- the inverse of `RegionInstanceRelations::symbolic_field_table` (`SymbolicFieldId → (RelationId,
  ordinal)`, the map `SymFieldText` already reverse-scans, `RegionInstance.h:620`).

It tags each `RecursiveComponent` with `Fusion ∈ {kUnclassified(anti-stub default), kFused, kJoint}`
and, when fused, a `binding_prefix` = the HEAD ordinals `{0..L-1}` of the **common preserved binding
prefix** across the cycle's within-cycle producers.

**The algorithm (route-only, fully compile-time decidable):**
```
field_of[SymbolicFieldId.v] = (relation.v, ordinal)          // invert symbolic_field_table
for each RecursiveComponent scc:
  scc_ids = { m.v : m in scc.members }
  prefix_len = +inf ; any_recursive = false
  for each RuleRoutingProjection r in R.rules with r.head.v in scc_ids:
    identity_dest = {} ; has_in_scc_route = false
    for each (src, head) in r.body_to_head:
      (src_rel, src_ord)   = field_of[src.v]
      (head_rel, head_ord) = field_of[head.v]                 // head_rel == r.head
      if src_rel not in scc_ids: continue                     // sourced OUTSIDE the cycle → skip
      has_in_scc_route = true
      if src_ord == head_ord: identity_dest.insert(head_ord)
    if not has_in_scc_route: continue                         // base/seed OR renamed edge
    any_recursive = true
    L = 0 ; while L in identity_dest: L++                     // maximal contiguous {0..L-1}
    prefix_len = min(prefix_len, L)
  scc.fusion = (any_recursive && prefix_len > 0) ? kFused : kJoint
  scc.binding_prefix = kFused ? {0..prefix_len-1} : {}
```

**Two non-obvious moves, both traced on real corpus:**
1. **A within-cycle producer = a rule with `head ∈ SCC` AND ≥1 route sourced from an SCC member.**
   Base/seed producers (corecursion_1's `ping :- add_edge`) carry no in-SCC route → excluded. A
   recursive clause that *renames* every cycle-carried var (two_inductions' `loop1(B):loop1(A),…`)
   records **no route** (`BuildRuleRoutingProjections` needs a shared `ParsedVariable::Id`) → zero
   within-cycle producers → **kJoint**. Sound conservative under-approximation: detect FUSED only
   when provable, default JOINT.
2. **Do NOT reuse `inherited_symbolic_fields` (P6.2 promotion).** Promotion is global/symmetric and
   can promote via an unrelated single-producer chain — corecursion_1's `shared-field F1=(ping.B,
   pong.B)` IS a promoted class even though the recursive edge preserves only column A. Reusing it
   would render `binding-prefix=(A, B)` — WRONG. The classifier reads the raw per-clause `rules`.
   This is the same clause-source-not-CSE'd-graph lesson P6.2 already established.
