## §1 What the cut IS + recommended slice

**Recommended slice A — ctest-model-only.** Two header changes to `RegionInstanceRelations`, gated by a
new `RegionInstanceP6` ctest suite; codegen/OptDiff byte-unchanged, zero `.dr` carriers (the exact
P3/P4/P5 model-gate precedent):

1. **`DeriveActivationEdge(src_state, src_fact, rule, dst)`** — a pure interning member inserting a
   `RuleActivationEdgeId` into `activation_edges`. **MAY cycle** (incl. self-loop = size-1 recursive
   component — LIFTS the P3 F18 acyclic restriction). Mints NO fact / request edge / routed result
   (activation ⟂ ownership ⟂ support). `dst` is **caller-supplied** (the P4 `KeyedState()` precedent),
   sidestepping the `RegionInstance.h`↔`RegionTemplate.rules` cross-layer link — computing
   `dst = RuleRoutingProjection(rule) image of src_fact` is P6.5 wiring.
2. **`RootedReachability` → least-fixpoint.** After the existing request-edge seeding, a monotone
   changed-flag worklist propagates liveness across `activation_edges`
   (`live.count(a.src_state) ⇒ live.insert(a.dst)`) to a least fixpoint. **Vacuous when the set is
   empty** (every real compile) → byte-identical to the P3 one-sweep there.

**Why A (not B/C/D):** the reconstruction-diffs pseudocode (`:590-592`) types `DeriveActivationEdge`
exactly as A — a pure intern over the *existing* reserved container, scoped "LIFT the P3 acyclic
restriction"; the closure is the necessary companion (a populatable edge set with an unclosable
reachability is self-contradictory — the P3 comment concedes "no propagation only because the set is
empty"). Slice B (a static `-region-out` render) is a *different artifact* — `RuleActivationEdgeId` is
keyed on concrete runtime `BindingStateId`/`RegionalFactId`, so no compile-time render of THAT type
exists without inventing a new component-level static edge type not in the P6.4 pseudocode; defer it.
Slice D (`EvaluateEpoch`/DRed/worklist) is P6.5/P6.6 by the doc's own phase labels.

## §2 Why it is sound + the P6.5 boundary

**Sound because unobservable to real compiles** — and (stronger than the "vacuous because empty"
argument) `RootedReachability` has **no real-compile caller at all**; `DeriveRegionalCensus` counts only
ports + row-contracts, never `activation_edges`; `Program::Build` reads `frozen.Query()`, never the
model half. So no path reaches codegen; the gate is STRUCTURAL (ctest + byte-stability), never
answer-equality. Termination: monotone add-only over the finite set; self-loop idempotent via the
`!live.count(dst)` guard.

**The P6.5 boundary (crisp).** P6.4 STOPS at the two pure primitives. **P6.5 `EvaluateEpoch`
(`reconstruction-diffs.md:594-620`) BEGINS** at real-compile wiring: (1) a rule/epoch sweep that CALLS
`DeriveActivationEdge`, computing `dst = RuleRoutingProjection(rule) image of src_fact` — crossing the
`RegionInstance.h`↔`RegionTemplate.rules` (P6.2) layer boundary that has NO cross-link at tip; (2) the
semi-naive worklist (pass B) interleaving `RootedReachability` with `EvaluateRule`/`AddDerivation`/
`RouteResults`; (3) pass-A within-epoch DRed support-loss (OVERDELETE/REDERIVE/INSERT over split
C_nr/C_r — also where `FactDerivation.support` upgrades from `int64` to the split
`DerivationSupportCount`); (4) `ApplyInputDeltas` + `Add/RemoveRequestEdge(request_deltas)`. **P6.5 is
the first place model and M3 could DIVERGE (B0/F1)** — the first non-structural gate. P6.6 =
`RetireUnreachableSCCs` / drain-before-retire. **P6.4 touches NONE of it.**

## §4 ctest desired states (predict-then-verify STRUCTURAL pins)

No `-region-out` shape change (slice A adds no render). The mandatory anchor is the ctest battery:

```
Gate J — intern, distinct from request/support:
  two DeriveActivationEdge calls → activation_edges.size()==2; derivations/request_edges/routed_results all 0
Gate K — cyclic closure (discriminates the P3 one-sweep):
  p<->q 2-cycle in activation_edges; AddRequestEdge roots ONLY state_p;
  RootedReachability(kRi) ⊇ {state_p, state_q}   // FAILS under the P3 one-sweep (never reads activation_edges)
Gate L — self-loop legal + terminates (lifts F18):  src==dst edge; rooted; reachability returns {…state_p}
Gate M — unrooted cycle stays DEAD (closure is ROOTED, not global-mark):  q<->r, neither rooted → both absent
Gate N — LEAST-FIXPOINT witness (the folded refuter finding; forces ≥2 iterations):
  a→b, b→c interned in ADVERSARIAL std::set order so Edge(b→c) is VISITED BEFORE b becomes live
  (choose src values so Edge(b→c) sorts before Edge(a→b)); root ONLY a; assert count(c)==1
  // a single non-fixpoint sweep-over-edges leaves c DEAD; only while(changed) reaches c
Gate O — re-derivation (liveness re-derived, not refcounted; folded R2/R3 minor):
  GateK 2-cycle rooted at p (both live) → RemoveRequestEdge(e) → RootedReachability drops BOTH to dead
  // a refcount collector would deadlock on the still-support>0 self-cycle
```
Regression: `TEST(RegionInstanceP3, AcyclicRequestForest)` (`:206-218`) stays byte-identical (its fresh
fixture builds zero activation edges; `activation_edges.size()==0` is per-fixture, not a global invariant).
Goal 3 / F18 hold TYPE-enforced: `RequestOwnerId` is `variant<RootLeaseId, PermanentRootId, RegionalMember>`,
never a `BindingStateId`, so a request-edge dest can never become a source — the request graph is a
depth-1 forest; only `RuleActivationEdgeId` (state→state) can cycle.
