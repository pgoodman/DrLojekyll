### §1.1 THE HEADLINE — clause-source, empirically forced (the decisive grounding)
The post-Optimize DataFlow graph **loses per-relation field identity via CSE**. `corecursion_1 -df`
(opt): the recursive UNION `merge.7` (`tag=connect/insert-union`) and `tuple.2`
(`tag=connect/select-proxy`) BOTH carry `table=%table:4 eqset=8` — `ping` and `pong` were CSE-merged
onto ONE model table, so the DataFlow views CANNOT tell you "ping.field0 routes from pong.field0". The
**parsed clauses retain per-relation identity** (`ping(A,B):add_edge(A,B).`, `pong(A,B):ping(A,B).`,
`ping(A,B):pong(A,X),add_edge(X,B).`). ⟹ **P6.2 walks parsed clauses**, filtered to frozen relations
(`ParsedDeclaration::Of(pred).Id() ∈ relation_schemas`). This is the SAME identity-preservation lesson
that flipped P6.1's insert-arm to the origin projection. The frozen-relation filter drops
messages/functors/foreign/@inline cleanly (never `relation_schemas`) and the filter SET is byte-stable
across all four optimization modes for every routing carrier (verified: corecursion_1,
tc_nonlinear_diff, redecl_1, folded_1, key_corecursion_1) — so the *routing analysis* is fully
mode-independent even where the *recursive-component* render is mode-faithful.

## §2. The design (SURVIVOR — machinery unchanged by the critique)
Full hunk-grain diffs in the design doc; the machinery survives the panel untouched.

- **§2.1 `struct RuleRoutingProjection { RuleId id; RelationId head;
  std::vector<std::pair<SymbolicFieldId,SymbolicFieldId>> body_to_head; };`** — one per PRODUCER CLAUSE
  of a frozen relation. A pair `(body_field, head_field)` = a directed value-flow for ONE shared
  variable. A clause with no frozen route is STILL stored with empty `body_to_head` (a base-case
  producer — its presence BLOCKS promotion of that head field; dropping it would wrongly promote a
  message-fed field). `head` is a deliberate add over the reconstruction-diffs sketch (the promotion
  groups producers by head).
- **§2.2 Region-global interner** on `RegionInstanceRelations` (peer of `schema_table`, DISTINCT
  domain): `std::map<std::pair<uint64_t,uint32_t>, SymbolicFieldId> symbolic_field_table;
  uint32_t next_symbolic_field;` + `InternSymbolicField` / `SymbolicFieldOf`. One flat region-global
  SymbolicFieldId per (relation, ordinal). NO migration of P5's table — P8 REBUILDS the composite trie.
- **§2.3 `AssignSymbolicFields(R, inst)`** — seed one SymbolicFieldId per (schema.id, i) in
  relation_schemas E-order × ascending ordinal (fixes the dense deterministic id space BEFORE rules,
  HP-9).
- **§2.4 `BuildRuleRoutingProjections(R, inst)`** — the clause-source walk (§1.1). For each frozen
  relation's decl, for each clause, for each group, for each POSITIVE body predicate whose
  `Of(pred).Id()` is frozen, emit `(SymFld(body,i), SymFld(head,j))` for each shared clause variable.
  RuleId = dense per-clause ordinal (relation_schemas E-order, then `Clauses()` parse order). Negated/
  aggregate/@product atoms drop out (positive-frozen-only under-approximation, Q5).
- **§2.5 `PromoteSharedSymbolicField(R, inst)`** — the corrected, coherent primitive. The
  reconstruction-diffs `producers = ProducerRulesOf(f_a) ∪ ProducerRulesOf(f_b)` union is INCOHERENT
  across relations (a producer of rel(f_a) only carries pairs `(*, field-of-f_a)`). SURVIVOR: a
  **directional per-head-field** rule — `union(SymFld(H,j), s)` iff EVERY producer clause of `H`
  sources `H.j` from exactly ONE frozen body field and all those per-producer sources are the SAME
  class (under current `find`). Empty source ⇒ base case ⇒ no promotion; ≥2 sources in one rule ⇒
  join ⇒ ambiguous ⇒ no promotion (the F16 co-occurrence trap, closed). A `while(changed)` union-find
  loop to a FIXPOINT (F28); union-by-min gives a deterministic class-minimum representative;
  `R.inherited_symbolic_fields[f.v] = find(f)`.
- **§2.6 Render** (`Format.cpp`, after the P6.1 recursive-component block, OWN width, gated): a `rule`
  block (skip empty `body_to_head`) + a `shared-field` block (skip singleton classes), + helpers
  `RelNameOf`/`SymFieldText`. NO census count (Q3). Pure suffix append — every existing line
  byte-identical.
- **§2.7 Build wiring** (Planning.cpp, after P6.1 populate, before census):
  `AssignSymbolicFields → R.rules = BuildRuleRoutingProjections → PromoteSharedSymbolicField`.

## §3. Panel — the 5 folded correctable fixes (empirically proven)
- **C1 (unanimous) — carrier mode-split.** The design's §7 carrier used a PURE copy-forwarding cycle
  `q(K,V):p(K,V). / p(K,V):q(K,V).` — canonicalization strips the vacuous p↔q self-loop in opt/nocf, so
  `recursive-component C0 members=(p, q)` appears only in nodf/none. **FIX (verified all-4-modes):**
  route p's back-edge through a JOIN like corecursion_1: `p(K,V):q(K,X),edge(X,V).` (new `#message
  edge`). Promotion story unchanged (`q:p` still unions q.*~p.*; a/b still block p.K; p.V's class still
  forms via `q:p`'s union INTO p.V).
- **C2 (decisive) — F28 fixpoint ungated.** All promotions in the exit-gate carrier are
  single-pass-reachable, so a buggy no-`while(changed)` impl ships green. **FIX:** add a dedicated
  `fixpoint_force.dr` (`p:a; p:b; a:c; b:c; c:src_c`) whose nodf E-order `c,p,a,b` walks head `p`
  BEFORE its sources — a single pass under-promotes p.K; only iteration 2 collapses it. The nodf/none
  `shared-field` member list is the BYTE referee: fixpoint → `members=(c.K,p.K,a.K,b.K)`; single-pass
  bug → `members=(c.K,a.K,b.K)` (p.K absent). (opt drops `p` entirely — nodf/none-only discrimination,
  mode-faithful.)
- **C3 — render order corrected.** Real E-order for the fixed carrier is `lookup,a,b,p,q` (the `#query`
  relation `lookup` sorts FIRST), so union-by-min rep = lookup's field and members ascend
  `(lookup.K, p.K, q.K)`; rendered rule ids non-contiguous (empty base producers stored-but-unrendered);
  p's recursive rule routes only `(q.K->p.K)` (p.V is edge/message-sourced, unrouted).
- **C4 — Q5 gated by existing goldens.** The existing `negate_1`/`negate_6`/`d5_recursive_negate`/
  `aggregate_1`/`average_weight` region goldens exercise the negation/aggregate exclusion — their `rule`
  lines must show NO route through the anti-join or `over(){}` summary. `PositivePredicates(g)` skips
  them structurally; the pin makes it load-bearing.
- **C5 — multi-redeclaration belt.** Confirm `Clauses()` spans the whole redecl group (verified: ping/
  tc/p/redecl_1 all appear under one decl); else aggregate over `UniqueRedeclarations()` (F31/
  F-K6-SHADOW precedent). `redecl_1` is the standing multi-clause pin.
